# Ancient 原始模型去顶版

当前地图恢复最初的 VPK 去顶模型。资源从首次打包版本 `cs2-sandbox-d630c9bbbacea8e3.exe` 内直接提取，几何未重新生成，也未使用 NAV 空缺填墙或后续封顶重建。只调整渲染：移除所有地图/底座线段描边，采用不透明双面石质材质，并平滑相邻曲面法线。人物、射击、烟雾、火焰、轨迹等动画保持当前实现。

地图采用浅灰绿地面、苔绿石墙、柔和明暗与空气感，同时保留墙体和地面的明度区分。墙体与掩体共用 128×128 程序风化纹理，采用世界坐标投影，无需原始模型 UV。材质参数和视觉验证见 [地图美术方向](map-art-direction.md)，不改变本文记录的原始地图几何。

## 第一版数据来源

- 资源：`maps/de_ancient/world_physics.vmdl_c`，原始碰撞 967,742 面。
- VPK SHA-256：`db67fb7c45e4a92a87473dc8d9dae0b5ead6887e282ecd7d98076f5c01af0d26`。
- NAV SHA-256：`967c483c0e2e4471834a9e0ba80432c8e9a8114e61ff5a6fb08c32b7331fc6d4`。
- 第一版导出器为 Source 2 Viewer CLI 20.0，简化器 meshoptimizer 0.25.0。
- 资产内记录的裁切参数：NAV 距离 128、墙高 136、屋顶阈值 92、地板深度 24 世界单位；坐标量化 0.05，简化误差上限 3。
- NAV 用作行走地面和裁切参考；墙体、地形和掩体来自 VPK。辅助 clip 体积、屋顶及部分微细节已在第一版转换中去除。

这是恢复已有资产，不是重新实现第一版转换算法。正常前端/EXE 构建直接嵌入该文件，无需再次读取 VPK/NAV。旧的 NAV 和封顶重建导出器保留供实验，PowerShell 入口必须显式传 `-Mode nav` 或 `-Mode collision`，避免默认构建时覆盖恢复结果；这些模式不生成当前第一版模型。

## 验证

```powershell
node tools/check-ancient-map.mjs
# 或直接校验归档版本
node tools/check-cutaway-map.mjs
```

校验精确资源摘要、来源、坐标、索引与面数。去顶模型存在有意的开放裁切边，不应用封闭重建模型的拓扑标准。浏览器回归验证无地图线段、不透明材质、地面支撑、显示层弹丸与地图接触、相机操作及现有回放动画。十人六道具样本为 89 次绘制、82,942 面，连续刷新未增加 GPU 几何体和纹理；不是硬件帧率承诺。

裁切后的碰撞表面仅用于显示层接触效果，不代表真实游戏视野、子弹穿透或投掷物物理。历史实验另见 [封顶重建版](ancient-collision-whitebox.md) 和 [NAV 版](ancient-nav-sandbox.md)。
