# 地图美术：柔光石质沙盘

## 视觉目标

地图采用低饱和石质材质、柔和受光、分层明暗和轻微空气感。以清晰呈现道路、墙体及高度关系为目标，让人物与对局特效保持视觉主体。

保留第一版 CS2 去顶几何与当前人物/道具/射击风格。按森林主题使用灰绿石材、苔藓色斑与浅绿色环境，地图不加轮廓线，不用全屏泛光模糊对局信息。

## 实现

- 地面 #E8EDDD，墙体 #A6B7AA，掩体 #B2BFA1，地形 #A8BC94，底座 #BFCBB4。实际显示还受光照、朝向和色调映射影响。
- 墙体与掩体共用一张程序生成的 128×128 RGBA 风化遮罩，混合灰绿底色、#648844 苔藓和 #D5DDBD 浅色风化斑。大块柔和色差配合近景细微颗粒，不添加砖缝或面边线。
- 纹理使用世界坐标三向投影，不依赖原始模型 UV；相邻模型共用采样位置，镜头移动时纹理固定在墙上。重复采样、线性过滤和 mipmap 减少远景闪烁；纹理随地图统一释放。
- 地图独立的 32×1 RGBA 明暗表，从 96 至 236 平滑变化，线性采样，柔化此前三档硬切换。
- 直接受光使用略暖的权重，环境填光偏冷；侧面亮度约为顶面的 86%。墙体比地面更深，保持路径和障碍区分。
- 仅地图有微弱暖色掠射亮边（面内柔光，不是线段描边）与最多 5.5% 的距离空气感。不会对人物、标签、弹丸或道具施加全局雾。
- 天空背景使用 1×64 RGBA 渐变：上方雾绿、下方浅绿白。没有天空球、云朵模型、粒子云或额外全屏后处理。
- 原有全局灯光、曝光、人物及特效的查找表和配色不变；地图仍是不透明双面材质，原始几何摘要保持不变。

## 验证与成本

GPU 同光照色板：地面 RGB 172/178/153，墙面采样点 138/150/124。自动检查明度差至少 20、地面和墙体均以绿色通道为主，避免再次全部泛白；同时确认人物查找表和 CT 蓝色不变。纹理检查覆盖无 UV 几何、相邻面接缝、暂停稳定性、共享纹理和苔藓明暗色差。浏览器检查 shader 编译错误、实际回放、暂停、拖动、道具、镜头操作与资源复用。

真实十人六道具样本为 89 次绘制、82,942 面；加入风化纹理不增加绘制批次或面数，地图自身仍为 76,138 面。明暗表 128 字节、背景渐变 256 字节；共享风化遮罩为 64 KiB 像素数据，包含 mipmap 约 85 KiB（均不含驱动对象开销）。每个地图片元增加三次遮罩采样，仅用于墙体和掩体；没有外部贴图文件或新增下载资源。

保留的原始碰撞裁切模型仍有开放边与局部细小结构；此改动调整材质和光感，不修改道路、墙体或 NAV 的形状。
