# 三维战术沙盘

Ancient、Dust2、Mirage、Inferno、Nuke、Anubis、Cache 回放均可通过侧栏的 **2D / 3D 沙盘** 切换地图渲染方式。首次默认进入三维，后续保留选择；未提供三维资产的地图继续使用二维。地图资产加载失败或 WebGL 不可用时，界面显示原因并回到二维。各地图来源、配色与资源预算见 [多地图支持](map-catalog.md)。

## 操作

- 左键拖拽旋转，右键或中键拖拽平移，滚轮平滑缩放；触控板双轴平移和捏合缩放继续支持。
- 单击地图表面，在约 800 ms 内平滑移至屏幕中心，仅平移 Demo X/Y（水平方向），保持相机高度、缩放和观察角度。高低地面均按实际点击点居中，点击背景不移动。
- 单击玩家仍为选择，单击投掷物保留分析入口；双击玩家或投掷物，以实体为中心观察。新拖拽、滚轮操作或重置视角会中断居中动画。
- Nuke 侧栏提供“上层 / 中层 / 下层”：上层显示完整模型；中层按地面 Z=-416 加站立身高 72，在 Z=-344 裁去更高建筑；下层沿用 Z=-480 剖视。中层仅裁地图及其阴影，人物和空中道具保持完整。切换不改变回放坐标和镜头。
- 默认视角为原视角的 150% 放大；侧栏“重置视角”恢复这个倍率及地图中心，并清除待完成的缩放；“纯净视图”隐藏侧栏及玩家卡，Escape 返回。
- 时间轴、倍速、玩家隐藏、画笔截图、录屏、击杀信息与道具分析继续使用现有入口。
- 反查道具的矩形区域沿用二维雷达投影。打开反查菜单时临时切回二维，关闭后恢复原三维偏好。

画布内没有新控制面板，场景采用正交相机、三档明暗、轮廓、柔和阴影和低面数圆柱人物。人物尺寸保持世界单位，名称保持屏幕可读尺寸。真实高度由坐标表达，不使用二维视图中的高度缩放效果。

玩家手中显示当前装备的低面数模型：七类武器轮廓，以及烟雾、闪光、高爆、燃烧瓶、燃烧弹、诱饵和 C4 的独立外形。飞行道具也使用对应模型与阵营色带，分类、资源预算和测试见 [三维持握装备](equipment-models.md)。

点击存活且未隐藏的玩家卡片可进入该玩家的第一人称回放；在 2D 中点击会切换至 3D。透视相机直接采样同一回放时钟下的 XYZ、yaw 和 pitch，暂停与跳转立即同步，不叠加追赶动画。当前数据没有精确眼部偏移，镜头采用脚底高度加 64 世界单位的固定站姿眼高，不受人物大小设置影响。自身身体、姓名与战术扇形隐藏，保留原有持握武器；其他玩家名称受场景遮挡。

点击其他玩家卡片可切换跟随目标，再次点击当前卡片、按 Escape 或点击侧栏“返回沙盘”会恢复进入前的沙盘位置、角度和倍率。“重置视角”退出跟随后重置沙盘。死亡、离场、隐藏玩家、切换回合或回放、进入道具分析或切回 2D 时退出跟随。第一人称期间关闭沙盘拖拽和滚轮操作；Nuke 临时显示完整的已有地图模型，退出后恢复原先的楼层裁切。此视角复用简化沙盘资产，不加载完整游戏地图。

第一人称致盲覆盖整个场景画布：被闪到时立即叠加最高 90% 不透明度的中性灰白遮罩，仍保留 10% 原始场景，短暂保持后按回放时钟平滑恢复，暂停不会继续淡出，倒退与直接跳转可以还原中间状态。`playerFlashes.ts` 预索引每名玩家的致盲区间；解析器的 `flashDuration` 是以秒计的总时长，`isBlinded: false` 优先于遗留的时长值。发生新的时长变化时重新触发；原始数据没有独立的闪光强度和每次命中时间，因此无法区分持续致盲期间两次时长完全相同、且中间没有采样到解除状态的闪光。片段从致盲中途开始时，使用已知结束时刻估算淡出进度。切换跟随玩家或退出第一人称后即时清除旧玩家的遮罩。遮罩只需两个三角面，直接在 WebGL 内绘制，截图与录制保留效果，不增加外部贴图或后处理渲染目标。

滚轮按输入幅度累积目标倍率，在渲染循环中按真实时间进行对数空间缓动（85 ms 响应时间常数），避免正交相机逐格跳变。反向滚动从当前可见倍率立即响应；缩放仍限制在 0.5–9 倍，暂停回放不影响镜头操作。

## 几何与坐标

浏览器按当前地图加载 `frontend/public/map/3d/<mapName>.json`，不会同时加载七张地图。Ancient 保留最初发布的原始 VPK 去顶模型，直接使用其碰撞墙体、地形与掩体，NAV 提供可行走地面及裁切参考；新增六图采用独立的原始碰撞去顶导出器。没有重新推断墙形或填实 NAV 空缺。Ancient 来源、版本摘要见 [ancient-3d.md](ancient-3d.md)。

统一坐标变换为 `scene = (demo.x, demo.z, -demo.y)`，反向为 `demo = (scene.x, -scene.z, scene.y)`。保留原始世界单位与右手系，地图、玩家、投掷物、轨迹、包点都使用同一个变换。

地图资源从首次打包 EXE 中逐字节恢复：76,138 面、约 2.79 MiB。保留原始模型去顶裁切结果，不再使用 NAV 空缺填块或后来的封顶重建。

原始地面、墙体、掩体及 A/B 标记沿用第一版数据；人物与投掷物仍使用 Demo 原始 XYZ，当前回放动画不回退。

地图与底座采用低饱和森林石色，墙体和掩体增加灰绿、苔藓色块与浅色风化纹理，背景为浅雾绿背景渐变，全局灯光保持原样。完全移除地图和底座的线段描边，面与面之间不再画灰线。地图材质不透明，避免薄面叠加变灰；去顶后的开放表面双面显示，相邻曲面使用平滑法线，实际硬拐角保留。

Ancient 采用柔光石质风格：浅灰绿地面、苔绿墙体、柔和明暗过渡、浅雾绿背景渐变与轻微空气感。墙体仍比地面深，人物和特效的全局光照、曝光、配色不变。材质参数见 [地图美术方向](map-art-direction.md)。

这是经过抽象的战术模型，不能用作射线可见性、碰撞或投掷物物理模拟依据；历史 Demo 与本机当前地图版本不同也可能造成局部偏差。

## 回放与性能

`sampleReplayFrame` 根据统一播放时间定位前后样本，生成只用于显示的 XYZ 与角度插值。暂停、倒退、时间轴跳转与道具分析都采用同一规则，不修改源帧。分析模式将片段内时间加上片段起点后再采样。

死亡、开枪、投掷物爆炸和装备状态仍来自当前数据帧；同一实体的爆炸位置可以作为飞行最后一段的终点，效果不会提前出现。跨回合、缺失实体、不合法坐标、玩家大位移或超过 500ms 的数据间隙不进行过渡。只有端点时，插值无法恢复样本间未记录的碰撞或转折。

三维烟雾支持高爆手雷炸烟：在观测到爆炸的数据帧，以爆炸位置和半径在烟雾中裁出局部球形缺口，范围外的烟雾保持原有形态。缺口保持 1 秒，再用 2 秒平滑缩小直至恢复。`smokeDispersal.ts` 按完整帧序列预索引爆炸的时间、位置和半径，采用三维距离区分高度，暂停、倒退和直接跳转不依赖实际播放过哪些帧。不同位置的连续爆炸各自形成缺口，HE 实体消失不会提前结束恢复；片段开始时已经生效的 HE 不补造新的爆炸事件。

`smokeHoleMask.ts` 在原有实例烟团的着色器中裁切局部表面，不缩放整团烟雾，也不改变范围外的颜色与透明度，不增加绘制批次或外部贴图。炸烟不重置 TTL；烟雾进入自身自然消散阶段后冻结缺口恢复，烟团继续按剩余寿命缩小，到期或实体消失立即结束，避免恢复动画让旧烟重新出现。匹配使用简化云团体积与爆炸半径，不模拟真实烟雾流体或墙体传播。`canClearSmoke: false` 可关闭此效果，配置变化会重新建立索引。

`playerDeaths.ts` 预索引连续样本中的存活→死亡事件。名称与朝向扇形在死亡时立即隐藏，身体变为 14 块共享几何的实例碎片，在约 800ms 内散开，随后完全消失，不保留地面残骸或选中光圈。动画直接由播放时间采样，暂停保持姿态、倒退可恢复、跳到死亡很久之后直接隐藏。片段开始时已死亡或断点后首次出现的尸体不补播动画。死亡位置固定，首次显示事件时向 NAV 和补充地面查询下落高度，无需逐帧做地面射线。

存活人物使用 90°、半径 165 世界单位的水平渐隐扇形表示 yaw，按队伍着色，跟随最短路径角度插值。扇形仅是朝向示意，不计算穿墙或烟雾遮挡后的真实可见范围；它不拦截鼠标拾取。材质共用一份 32×1 的渐隐查找纹理。

三维射击由 `shotFlights.ts` 预索引实际 `shotsFired` 事件，T 方显示黄色弹丸、CT 方显示蓝色弹丸，阵营规则与人物一致。开火时显示约 70ms 的双色枪口闪光，随后弹丸以每毫秒 4.8 世界单位沿事件的 `shotYaw` 与 pitch 飞行，最多飞行 1,800 单位。弹丸只带 64 单位以内的短尾迹，发射位置与方向固定；射手继续移动、转向、停止开火或死亡都不会拖动或清除已经发出的子弹，连续射击可同时显示多颗弹丸。

弹丸与人物简化包围体和恢复后的地图表面取最近接触点，到达后显示约 60ms 小闪点；超过射程则消失。源碰撞模型的裁切结果重新参与显示层射线，但不能等同原游戏的真实挡弹或穿透判定。人物碰撞按连续位置计算，地图射线每个事件查询一次；回放时钟和对象池不变。

这是为了读懂交火方向而放慢的视觉表现，并非真实子弹物理或命中判定。当前数据没有每颗子弹的精确发射时间、弹孔或伤害接触点：同一样本累计多枪时只显示一次代表性发射，碰撞依据简化几何计算，不修改原始伤害、血量或击杀结果。

三维包按需加载。Mesh、标签纹理与材质复用，轨迹使用可更新缓冲，烟雾、火焰和掉落物使用实例化绘制。逐刷新操作直接更新 Three 对象，Vue 只提供播放时钟与设置；切换视图时释放画布、控制器和 GPU 资源。

飞行尾迹由 `projectileTrails.ts` 预索引每个连续飞行段的真实 XYZ 样本构成，只显示当前时间以前的顶点，并以实时插值位置作为末端。原始 `trajectory` 是稀疏的出手/碰撞检查点，缺少中间飞行位置与时间戳，直接连接它们会把抛物线画成直弦。三维层补齐逐帧历史路径，暂停、倒退和跳转无需重放来积累尾迹，也不会显示未来轨迹。源回放数据与解析器保持原样。

投掷物按投掷者的当前阵营配色，CT 偏蓝、T 偏黄；同阵营的烟雾、闪光、高爆、燃烧和诱饵轨迹共用同一份颜色及透明度材质，轨迹不再按道具类型改色。烟雾和燃烧区域通过实例颜色区分双方，不增加绘制批次；投掷者已死亡或离场时仍可根据回放元数据识别阵营，未知归属采用中性灰。

烟雾与燃烧区域都不绘制底部圆环。燃烧区域由 61 个低面数火焰尖刺组成，填满中心并沿外缘排列 24 个尖刺，通过火焰本身显示范围轮廓。铺开后位置保持稳定，只有高度轻微变化；全部火焰共用一个实例批次，可容纳十个同时生效的完整燃烧区域。

烟雾在首次生效后约 900 毫秒内从爆点膨胀，中心烟团先出现、周围烟团稍后展开。火焰约 650 毫秒内由中心向外铺开，外围尖刺依次长起；短寿命配置会相应缩短展开时间。生效时刻从原始帧预先索引，独立于实际剩余寿命，支持新 ID 的燃烧区域；暂停、倒放和跳转都由统一回放时钟确定形态。剪辑开头或数据断点后已经存在的效果直接显示稳定状态，避免错误重播出生动画。仍复用原有实例批次，不增加网格、贴图或绘制批次。

高爆手雷使用立体爆炸团和八块向外散开的碎块，约 650ms 后完全消失，不绘制底部圆圈或遗留轮廓。闪光弹使用向外扩散、逐渐淡出的圆环。二者均带投掷方的蓝／黄色调，动画由回放时间采样。`projectileStyle.ts` 统一数字 ID、旧名称别名和后端默认时长，避免高爆爆炸进度长时间停在起点；效果不会超过记录的 TTL，尤其不将短于默认值的燃烧延长。

## 验证

在 `frontend` 目录运行：

```powershell
pnpm test:local
pnpm test:3d
pnpm test:recording
pnpm build
```

浏览器检查使用独立的内存 API，验证真实地图资产加载、森林石质材质、XYZ 插值、爆炸时间点、到期效果消失、加粗弹道与枪口火焰、射击方向与时间采样、死亡当帧射击、碎裂时间采样与倒退、碎屑到期消失、死亡名称和扇形显隐、队伍扇形朝向、实体复用、点击烟雾、相机操作、销毁、加载失败回退、视图偏好和反查切换。它不会写入用户 Demo 库。截图在 `tmp/ancient-3d-qa/`，包含真实射击，以及死亡前、碎裂中和消失后的近景。上述 Vite 测试按顺序运行，避免多个测试同时重建共享的开发依赖缓存。

可用已经解析的 Ancient 回合进行只读视觉检查：

```powershell
$env:CS_3D_ROUND_DIR = 'C:\path\to\cached-ancient-directory'
pnpm test:3d
```

目录需包含 `entry.json` 和 `1.json`。打包仍使用根目录 `build-local.ps1`，`map/3d` 与前端资源一起嵌入 EXE。

根目录运行 `node tools/check-ancient-map.mjs` 验证当前第一版资源的精确摘要、来源、坐标、顶点索引和面数。浏览器回归验证地图没有线条覆盖层、不透明表面无叠色，以及原有回放和交互。NAV 与封顶重建工具保留作历史实验，需显式选择模式才会替换地图。

加入持握装备后的真实回合十名玩家、六个投掷物：118 次绘制、84,926 面，连续 90 次刷新后几何体和纹理数量不增长。地图恢复第一版 2,930,526 字节、76,138 面和四个表面批次。地图使用一份 32×1 明暗查找表、1×64 背景渐变和共用的 128×128 程序风化遮罩；风化纹理包含 mipmap 约 85 KiB 像素数据，不增加绘制批次、面数或外部贴图文件。

原始模型的裁切边属于开放边，不套用封顶重建或 NAV 填块的闭合性测试。验证当前资产与首次打包资源完全一致，不能沿用后续实验版本的面数、地面支撑率或几何完整性结论。

真实回放烟雾弹的近景检查保留了 44 个已发生轨迹顶点，包含完整弧线和碰撞转折。轨迹末端跟随播放时钟，倒退时缩短，不依赖实际播放过哪些帧。浏览器检查也覆盖了先前实时末端所占顶点的恢复，避免前后拖动破坏路径。

前端回归、浏览器三维交互、原有 MP4 录制测试及 `go test -mod=vendor ./cmd/... ./pkg/...` 通过。打包后的 EXE 使用隔离缓存启动，并验证了内嵌地图文件与源资产哈希一致、生产页面可以显示三维回放。

现有工作区检查限制：`go test ./...` 会扫到忽略目录 `tmp` 中多个带 `main` 的旧预览脚本而失败；全量 `tsc --noEmit` 仍报告既有的 `protobufjs` 与 `App.vue` 声明缺失，以及 `projectileEffects.ts` 的字符串索引类型错误。它们不影响上述源码包测试和 Vite 生产构建。
