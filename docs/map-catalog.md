## 来源与导出

源文件来自用户提供的本地 Steam `game/csgo/maps` 目录。逐图提取包内 `maps/<map>.nav`、`maps/<map>/world_physics.vmdl_c` 和包点实体；无需完整贴图、渲染模型或 VPK 随应用发布。资产内保存来源 SHA-256、裁切参数、源面数及坐标约定。

新增导出器直接裁切真实碰撞三角形，NAV 仅提供行走地面和附近高度参考。保留距 NAV 128 世界单位内的主要结构，墙高 136、屋顶阈值 92、地板深度 24；大三角形先作局部采样，再裁切，避免仅凭大墙中心点决定整墙保留。所有相近 X/Y 的独立楼层参与高度查询，楼层不会被压到同一个高度。

源碰撞包含薄面、开放边和细小结构；裁切仍有开放边，不是封闭建筑复刻。meshoptimizer 在 3 世界单位绝对误差内减面，保护实际几何关系优先于强行达到目标面数，因此 Inferno、Cache 相对大一些。地图用于战术显示，不能当作精确碰撞、穿透或视野模拟。

包点碰撞模型先应用实体的缩放、角度和 origin，再放置到对应高度的 NAV 地面。Inferno B、Anubis 和 Cache 的局部模型需要这个变换。Ancient JSON 保持原先归档文件的逐字节内容，新增导出流程不会覆盖它。

```powershell
# 首次自动准备固定版本的离线转换工具；只读取原始地图包
.\tools\export-map-cutaways.ps1
# 仅重新生成指定图，复用已经提取的中间数据
.\tools\export-map-cutaways.ps1 -Maps de_nuke -ReuseExports
node tools/check-map-cutaways.mjs
```

工具为 Source 2 Viewer CLI 20.0（下载校验 SHA-256）及 meshoptimizer 0.25.0，仅用于离线转换。正常构建直接打包 JSON，终端用户无需 Steam 或转换工具。

## Nuke 剖视

Nuke 的 A 点约 Z=-412、B 点约 Z=-767，原始 NAV 高度及重叠的上下层均保留。侧栏提供三个层级：

- 上层：原先的“全部”，不裁切，默认显示完整模型。
- 中层：地面解剖视角，以主地面 Z=-416 加站立身高 72，在 Z=-344 向上裁掉建筑及其阴影。裁切只作用于地图，人物、空中道具与弹道保持完整。
- 下层：沿用 Z=-480 的原有剖视行为。

切换不改变相机或实体坐标，射线选择忽略被裁掉的地图表面。剖视模式只改变显示，回放时钟、事件和已有接触查询仍保留。
