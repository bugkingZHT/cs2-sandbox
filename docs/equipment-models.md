# 三维持握装备

存活玩家根据当前数据帧的 `activeWeapon` 显示手持模型，跟随人物 yaw 和尺寸设置。枪械跟随 pitch，刀和投掷物保持竖直持握，刀尖朝上。C4 在手持、背负与落地状态下统一使用红色。切换武器是离散事件，不提前插值；暂停、倒退和跳转直接恢复对应装备。死亡、隐藏玩家或未知装备时不保留手持模型。

| 外形分类 | 对应装备 |
| --- | --- |
| 狙击枪：长枪管、瞄准镜 | AWP、SSG 08、SCAR-20、G3SG1 |
| 步枪：枪托、护木、弹匣 | AK-47、M4A4、M4A1-S、Galil AR、FAMAS、AUG、SG 553 |
| 冲锋枪：短枪身、长弹匣 | MAC-10、MP9、MP7、MP5-SD、UMP-45、P90、PP-Bizon |
| 霰弹枪：管状弹仓、泵动护木 | Nova、XM1014、MAG-7、Sawed-Off |
| 机枪：宽枪身、箱式供弹、支架 | M249、Negev |
| 手枪：短套筒、握把 | 常规手枪；Zeus 暂时使用此轮廓 |
| 刀：刀柄、护手、刀刃 | 标准刀和命名刀型 |

各分类共享一种抽象外形，不逐把还原武器皮肤或机械结构。烟雾弹为灰黑色圆柱；闪光弹为军绿色细腰粗两端罐体；高爆手雷为军绿色球体；燃烧瓶为带瓶颈和布条的红色瓶子；燃烧弹与烟雾弹外形一致，主体为红色；诱饵弹为窄罐；C4 为带屏幕键盘的红色炸药包。道具阵营色带保持窄条，保留主体颜色的辨识度。

飞行道具与手持道具共享几何体，飞行模型上的色带继续采用 CT 蓝、T 黄。轨迹、烟雾、火焰和爆炸效果沿用原有阵营配色与回放时钟。C4 持握时隐藏背负标记，落地与安放状态也使用同一个炸药包模型。

`equipmentKinds.ts` 使用本仓库 Go 解析器的 `EquipmentType` 编号和常用武器名称，不使用游戏 item-definition 编号。`equipment.ts` 的冲锋枪、霰弹枪、机枪、自动狙击枪和 Zeus 映射同步修正；406 是拆弹器，不显示为 Zeus。回归测试从 Go 源码读取枚举核对分类。

`equipmentModels.ts` 将简单部件合并成顶点着色几何体，每种模型不超过 350 个三角面，主体和阵营标记各一次绘制；双臂另外合并为一次绘制。全部模型共用一个主体 Toon 材质，切换只更新几何体引用，不创建新 Mesh、贴图或外部模型资源。场景销毁时释放未挂载的缓存变体。

枪械持握位置前移，标准人物比例下普通枪械的枪管末端与枪口效果位于朝向前方 48 世界单位，狙击枪为 76 单位；狙击枪外露枪管为步枪的三倍长。每次射击保存发射时的枪口距离，换枪不会挪动已发射弹道。枪口之前的贴身目标立即接触，避免枪管较长导致穿过近处人物。此处仍为显示层示意，不修改 Demo 的真实伤害。

验证：前端目录运行 `pnpm test:local`、`pnpm test:equipment`、`pnpm test:3d`。装备浏览器测试检查全部外形、武器切换时间、朝向、死亡/隐藏、C4、几何共享和资源释放，并输出 `tmp/equipment-3d-qa/held-equipment.png`。
